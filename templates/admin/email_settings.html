Set Up SMTP

In your PowerShell terminal, set these variables before running the Flask app:

$env:SMTP_HOST="smtp.gmail.com"
$env:SMTP_PORT="587"
$env:SMTP_USER="your-email@gmail.com"
$env:SMTP_PASSWORD="your-app-password"
$env:MAIL_DEFAULT_SENDER="your-email@gmail.com"
python app.py

For Gmail, use an app password where supported, not your account password. Restart the app after changing settings. SMTP requires a working internet connection.
